# v113 — a docs entry on a card can carry a `ref:` (bc-xl7n.191)

`public/app.js` is the only shell file this touches: `docUrl` takes an optional third
argument and appends `&ref=<ref>` to the `/doc` link, and the card's docs list passes the
entry's `ref`. A decision block's `docs:` entry written as `{path, label, ref: origin/main}`
now opens the file as that ref has it, not the copy on disk.

A v112 `app.js` under a v113 server is harmless: the entry's `ref` is simply ignored and the
link opens the on-disk file, as before. A v113 `app.js` against a v112 server never sees a
`ref` on any entry, so nothing changes. Nothing else in `SHELL` moves.
