# v125 — `is:` tokens replace the Beads toggle (bc-qzng7.11)

The Beads pane's Open / Closed / All toggle (bc-yjekg.3) is gone. Its place is taken by
`is:open`, `is:closed` and `is:all` typed into either bead search box — Home's bead box
and the ledger's id box — which go to that side and carry the other words with them.
Five files in `SHELL` change together:

| file | what changed |
|---|---|
| `public/viewbar.js` | `paintToggle` and the toggle's click handler removed; `parseSide` / `beadsTyped` added; `beadsGo(side, text)` carries the words; `window.beadcause.beads` published |
| `public/app.js` | the bead box's `set` reads tokens (`typeBeadQuery`); `window.beadcause.beadSearch` published |
| `public/history.js` | the id box reads tokens; `ledger.setStatus(list, { id })`; the `beadcause:ledger` event, which only the toggle heard, is gone |
| `public/index.html` | the two `[data-beads-toggle]` hosts removed |
| `public/style.css` | `.beadstoggle` and `.beadstoggle-opt` removed |

**Why this one is a bump.** v124's `viewbar.js` and `index.html` against v125's
`style.css` still draw the toggle into its hosts — and with its rules gone they draw it
as three bare browser buttons run together at the top of the list, a control with no
layout. That is the broken direction, not the merely older one, so the cache moves.

The other mixes are harmless: v125's `viewbar.js` against v124's `index.html` never
draws into the old hosts (they stay `hidden`), v124's `app.js` or `history.js` against
v125's `viewbar.js` search the words as typed, and v125's boxes against v124's
`viewbar.js` find no `window.beadcause.beads` and do the same.

**`SHELL` is unchanged.** No file is added or renamed.
