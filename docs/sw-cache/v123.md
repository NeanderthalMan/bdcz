# v123 — one bar, at the bottom of a phone and down the left of a desk; Find (bc-qzng7.4)

Phase 4 of the navigation redesign (bc-qzng7). The view row is now the app's only
navigation, and it moves:

- **Phone (under 1100px):** a tab bar at the foot of the screen — Inbox (with its badge),
  Work, ＋ New, Beads, Find. The bar fits the screen instead of scrolling sideways. The
  floating ＋ is gone because the bar has one; its panels open above the bar.
- **Desk (1100px and over):** a rail down the left — Inbox, Work, New, Beads, and Find at
  the bottom. The detail drawer (`public/drawer.js`) docks as a pane beside the list
  instead of a sheet over it: no backdrop, and the page makes room while it is open
  (`html.drawer-docked`).
- **Find** (`public/find.js`, new): one box for beads (`/api/beads`), chats, pull requests
  and every page in the app. ⌘K / Ctrl+K on a desk, the bar's Find on a phone. The bar
  loads it on first use. `test/findpages.mjs` fails the build when a page in `public/` is
  neither listed in Find nor named as not a place.

It is still one element (`.viewbar`) with one script behind it. What changed is where the
body's flex column puts it, how a pill is drawn, and two action items (`.viewpill-act`).

| file | what is new |
|---|---|
| `public/viewbar.js` | ＋ (`data-act="compose"`, drawn while the page has a create) and Find (`data-act="find"`) on the bar; `openFind` loading `find.js` on demand; ⌘K before it is loaded |
| `public/find.js` | new, and added to `SHELL` |
| `public/drawer.js` | `drawer-docked` on `<html>` while the drawer is open |
| `public/style.css` | the bar (under 1100px) and the rail (1100px and over), the docked drawer, Find |

**Mixed pairs:**

- v123's `style.css` with v122's `viewbar.js` draws the old pills as a bottom bar with
  no ＋ and no Find, and hides the floating ＋ only when the bar has one — so a create
  is still reachable, but Find is not.
- v122's `style.css` with v123's `viewbar.js` draws New and Find as two more pills at the
  end of a sideways-scrolling top row. They work, but the bar is in the wrong place.
- A v122 shell without `find.js` precached cannot open Find offline. The bar's Find then
  does nothing until the network answers.
