# v122 — Work's details lose their tab rows (bc-qzng7.9)

Phase 3b of the navigation redesign (bc-qzng7). The advocate console is one of Work's
details panes since v120. This version takes away the two rows of tabs it still drew:

- the console's **Advocates / PRs / Mirror** chips;
- the PRs section's **Open PRs / Merge queue** switch.

Both stay in the markup, hidden, because public/montabs.js and public/mergeboard.js keep
their sections by them. Which section is up is now set by the address alone, and Work links
to each one:

| link on Work | address | section |
|---|---|---|
| `details ›` (health line) | `#advocates` | the roster |
| `mirror ›` (health line) | `#advocates?tab=mirror` | Mirror |
| `merge queue ›` (Stage: In review) | `#advocates?tab=prs&sub=queue` | the merge queue |

A bare `tab=prs` (what `/prs`, `/pulls` and every notification about the board hop to) is
still Open PRs; `sub=` is `public/mergeboard.js`'s key beside montabs' `tab=`.

v121 is phase 5's (bc-qzng7.5, PR #356). If that has not landed when this one does,
`test/swcache.mjs` reports the missing note for v121 until it does.

Five files in `SHELL` change together:

| file | what is new |
|---|---|
| `public/index.html` | the console's three chips and the PRs switch carry `hidden` |
| `public/montabs.js` | in the shell, `initial()` and `moved()` read the address (no stored fallback), and `panes.onQuery` re-reads it while the pane is up |
| `public/mergeboard.js` | in the shell, the address's `sub=` picks Open PRs or the merge queue |
| `public/app.js` | `mirror ›` on the health line, `merge queue ›` over the In review list |
| `public/style.css` | the chip line as a bare status line, `.prs-tabs[hidden]`, `.work-queue` |

**Mixed pairs:**

- v122's `index.html` with v121's `montabs.js` hides the chips, but the old file still
  brings back whichever section was up last time (Mirror included), with no visible way
  to the roster except a reload.
- v121's `index.html` with v122's `montabs.js` draws the old chips, and they still work.
  Arriving on the pane reads the address, so a chip choice does not survive leaving and
  coming back.
