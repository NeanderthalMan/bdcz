# v114 — one Beads pill where Ledger and All Beads were (bc-yjekg.3)

`public/viewbar.js`, `public/index.html`, `public/style.css` and `public/history.js` move
together. The row draws one `Beads` pill where `Ledger` and `All Beads` were, and fills an
Open / Closed / All toggle into two `[data-beads-toggle]` hosts that only the new
`index.html` has; `history.js` publishes `window.beadcause.ledger` for the toggle to set the
status filter through.

bc-yjekg.1 rides the same bump: Advocates, Releases, Config and every repo view move off
the row into a menu the trailing ⋯ pill opens, styled by new `.viewpill-more` and
`.viewmenu` rules in `style.css` — a v114 `viewbar.js` over a v113 stylesheet would draw
that menu as an unpositioned block under the row.

A v113 `index.html` under a v114 `viewbar.js` has no toggle hosts, so the Beads pill still
lands where you last pointed it and the toggle is simply not drawn. A v114 `viewbar.js`
without the v114 `history.js` falls back to writing the status into the hash, which the
old `history.js` reads on build. A missing stylesheet half is an unstyled toggle, which is
why this is a bump rather than a hope.
