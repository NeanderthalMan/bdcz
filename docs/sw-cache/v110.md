# v110 — the docket draws deploys, folded (bc-xl7n.151)

`/api/docket` now carries a `deployed` event for each deploy that carried one of the
family's merges, plus `deploysKnown` and `unjournaled` on the payload, and
`public/docket.js` learns to draw them: a 🚀 line under the machine fold, and a note in
the chronology header when merges shipped before the deploy journal begins.

| half | what is new |
|---|---|
| `public/docket.js` | the `deployed` glyph and sentence; the header says deploys may be missing when the board is cold, and counts `unjournaled` merges |

**No mix of the two versions breaks anything.** v109's cached `docket.js` against a v110
server draws an unknown kind with the fallback glyph and no sentence, folded with the
rest of the machine lines; v110's page against a v109 server simply never sees a
`deployed` event and reads `unjournaled` as absent. The bump exists so the precached
`/docket.js` is replaced and the new lines are drawn at all.

**`SHELL` is unchanged.** No file is added or renamed.
