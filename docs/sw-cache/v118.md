# v118 — the Settings screen, and the doors that moved to it (bc-qzng7.1)

The `config` pane becomes the app's Settings screen: a grouped list at `#config` whose
rows open pages at `#config?p=<page>` — This space, Advocate, Repos in this space,
Notifications, This machine, All settings, Reference. The doors move with it: the Config
pill leaves the row, the mark's menu loses its Admin, Notification settings and Switch
account rows, the inbox header loses its ⚖️, and the space picker gains a first row,
**⚙ Settings**. Five files in `SHELL` change together, and the reason this needs a
version is that **one of them removes a door another one adds**.

| half | what is new |
|---|---|
| `public/config.js` | the list, the seven pages, the Advocate page and its `/api/advocate` presses; reads `account.who`, `account.onChange`, `account.nativeNotifications` |
| `public/accountbar.js` | the menu holds page actions only; exposes `who`, `onChange`, `nativeNotifications`, `openNotifications`; the trigger is ⋮ |
| `public/spacebar.js` | the `go:settings` row and `openSettings()` |
| `public/viewbar.js` | no Config pill |
| `public/style.css` | `.settings*`, `.settings-counts`, `.settings-details`, `.settings-up` |
| `public/index.html` | no `#foundations-link` |

**A mixed pair can strand Admin and the account picker, which is the failure the version
exists to prevent.** v118's `accountbar.js` against v117's `config.js` and `spacebar.js`
is a phone with no Admin row, no Switch account row and no Settings door — the account
picker is reachable from nowhere until the next deploy. The page works, so nothing on
screen says so.

The other direction is merely ugly: v118's `config.js` against v117's `style.css` draws
the Settings list as unstyled links, and v117's `viewbar.js` beside it still offers a
Config pill that opens a list rather than the card it used to.

**`SHELL` is unchanged.** No file is added or renamed. The seven standalone pages that
gained a `‹ Settings` link (`admin`, `foundations`, `term`, `flow`, `requirements`,
`skills`, `sounds`) need nothing from the shell to draw it — a plain anchor and one
stylesheet rule, absent from v117's stylesheet only as styling.
