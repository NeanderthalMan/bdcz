# v120 — Work: My Efforts, Chats, Advocates and Releases become one destination (bc-qzng7.3)

Phase 3 of the navigation redesign (bc-qzng7). The row is now **Inbox · Work · Beads**.

- **Work** is the old My Efforts pill, renamed (the id stays `epics`). Each effort card
  has a pipeline strip under it: ready → in session → in review → merged, not shipped →
  shipped.
- Your **chats** are drawn under the board. They are no longer in Inbox's list or its count.
- One **health line** sits on top of Work ("N sessions running · M ready · K blocked").
  Its "details ›" opens the advocate console, and launchd/router trouble surfaces there
  only when it is wrong.
- A **Stage** filter on Work swaps the board for the pull requests in review, or for
  those merged but not yet live. This is the PR board and Releases folded in.
- The Chats, Advocates and Releases pills are gone, and so is the ⋯ menu while no repo
  declares a view.
- The console and Releases panes, and every address they had, light Work. The lit
  Work pill stays a button on them, as the way back to the board.
- ＋ on Work opens a panel whose first row starts a chat.

Five files in `SHELL` change together:

| file | what is new |
|---|---|
| `public/inboxfilter.js` | `epics` relabelled Work (🛠️) with `filters: ['stage']`; the Stage group (`STAGES`, `setStage`, `stageOf`, `stage()`, `stageCounts`); `work: true` on the session kind, keeping chats out of Inbox's count; `session` mapped to `epics` in `set` |
| `public/viewbar.js` | the Work pill (`views: ['advocates', 'releases']`, `kinds: ['session']`, `back: true`); the Chats, Advocates and Releases pills removed; `away` in `draw`, which keeps the lit Work pill a button on a details pane |
| `public/app.js` | `loadWork` / `workHealthHtml`, `workPipeline` / `workStripHtml` on each card, the Stage list and the chats under the board, chats out of the Inbox list, `boardWanted` true on Work, and the chat row in Work's ＋ panel |
| `public/style.css` | `.work-health`, `.work-strip`, `.work-step` and its colourings, `.work-chats` |
| `public/warm.js` | the ledger entry moved after Work's three (`prs`, `advocates`, `releases`), which Work now draws from |

**Which mixed pairs break:**

- v119's `viewbar.js` with v120's `inboxfilter.js` still draws a Chats pill. Tapping it
  now lands on Work, so it is a second Work pill under the wrong name.
- v120's `viewbar.js` with v119's `inboxfilter.js` draws Work with no Stage filter, and
  the old file still counts chats into Inbox. The badge then says more than the Inbox
  list shows.
- v119's `style.css` with v120's `app.js` draws the strip and the health line as
  unstyled inline text inside every effort card.
